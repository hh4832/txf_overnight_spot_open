# Research discipline
Only modify this repository. Python 3.11; core logic in src, notebook only runner.
No look-ahead bias, future quantile leakage, silent forward-fill, silent date shifts,
contract-roll discontinuity contamination, adjusted/unadjusted mixing, threshold fitting
on evaluation samples, invented results or silently dropped observations.
Never declare validity from one p-value or profitability before costs, slippage and execution analysis.
Separate hypotheses, rules, measured results, interpretations and unverified claims.
Every candidate event retains exclusion reason; raw source hashes and Git SHA are required.
No credentials, account numbers, certificate files, caches or research outputs in Git.
Use chronological expanding OOS and historical-only quantiles; preserve old run folders.
H2 nonsignificance does not prove incorporation. No TOST without predeclared margin.
Synthetic fixtures must always be labeled SYNTHETIC_SMOKE_ONLY. Live failures cannot fall back to them.
Report counterarguments, annual/regime consistency, small samples and selection limitations.
Changes to data semantics require direct tests and explicit documentation.

v0.1.1: preserve all raw caches and prior run folders. Quarantine unverified
13:45 and 05:00 boundary records, exclude affected in-range events, and log
out-of-range anomalies without blocking pilot. Verify wheel by SHA256 and
platform before installation from authenticated private Drive file ID.

v0.1.2: validation mode is an isolated, bounded data-quality audit. It must
NOT run regression, OOS, HAC, p-value estimation, hyperparameter search, or
trade-signal classification. Preserve pilot/full constraints. Compare every
VALID event with unmodified source bars, time availability, actual contract,
verified adjusted spot open/close and recomputed return identities. Keep every
EXCLUDED event and each provider anomaly for review. Never hide an audit
mismatch behind a success label; never mislabel synthetic fixtures as live.
Nominal 300/840 minute counts are descriptive, not proof of a trading outage.
Use new run folders and checksum-checked cache; preserve existing raw data.

v0.1.3: Exchange-verified 2026 monthly TXF expiry dates are explicit;
the expiring contract's 13:29 start-labelled last minute is distinct from
normal 13:44, and no expiring-month night session exists. NEVER mix 202607
13:29 with 202608 04:59 as an overnight return. Boundary records are preserved
and audit-visible; default boundary status remains unresolved/excluded. An
explicitly documented non-price marker can be ignored only with flat zero
volume, identical OHLC/selected close, same contract and reviewed evidence.
Keep provider anomalies and warning history even for retained events.
Missing minute intervals are unobserved timestamps, not proven API loss;
do not fill. v0.1.2 status comparisons are inferred, not archived runs.

v0.1.4: This repo is a PERSONAL trading-reference tool, not a paper. Use
FinLab adjusted 0050 prices; TXF adaptive exact 13:45/13:44 and next-day
05:00/04:59. Preserve strict same-month checks, no missing minute fill,
raw boundary audit, annual stratification, and a chronological 252+ prior

overrides for exchange-shifted days. Report sample insufficiency and never
label historical frequencies as signals or trading profit. Full multi-year
